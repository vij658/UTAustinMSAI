# DocDesk

A question-answering assistant over public consumer-banking documents (fees, overdrafts, deposit insurance, credit reports), built one layer at a time while following Track H of my MSAI video roadmap.

Public data only: no work data, no customer data. Secrets live in `.env`, which Git ignores.
