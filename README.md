# UT Austin MSAI video roadmap

A watch-while-biking and study-at-the-desk video plan for the UT Austin online MS in AI (Spring 2027), growing toward designing large-scale GenAI tech stacks.

- Start with [ROADMAP.md](ROADMAP.md): how to use it, the weekly rhythm, the order of play, how it maps to the UT courses, known gaps and what is pending. [MORNING.md](MORNING.md) lists pages I could not open.
- The tracks are in [tracks/](tracks/): A AI math, B AI and ML concepts, C the GenAI stack and enterprise architecture, D enterprise tech stack (bike), E enterprise tech stack (desk), F the UT course tracker, G end-to-end GenAI from data to a governed production system.
- `python3 tools/build_html.py` builds the HTML pages in `html/` from the track files (needs `pip install markdown`). [RESUME.md](RESUME.md) says where the work stands.

Every video was checked to exist (YouTube oEmbed returned the same ID, with title and channel copied as returned) and its length was read from its YouTube page. None was watched. See "How much to trust this" in ROADMAP.md.
